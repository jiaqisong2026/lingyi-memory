# 灵忆 LingYi — 面向银河麒麟的 OS Agent 自学习记忆优化系统

> 灵忆（LingYi）是一套为银河麒麟操作系统上的 AI 智能体（OS Agent）设计实现的自学习记忆优化系统。
> 它以五级记忆架构为核心，解决智能体"短期能聊、长期失忆"的关键问题，
> 实现记忆的自动写入、精准检索、可靠遗忘与可信治理。

---

## 核心特性

- **五级记忆架构**：覆盖工作记忆、短期、中期、长期与程序性记忆的完整 OS 级记忆管理闭环
- **混合检索**：FTS5 全文 + BM25 关键词 + RRF 融合重排，支持快速、准确的记忆召回
- **多特征智能关键词提取**：面向命令、文件名、领域词的中文分词与实体识别
- **自适应动态分层检索**：按查询意图动态切换检索层级，控制开销与延迟
- **双时态知识图谱**：区分知识与事实的时效状态，支持冲突检测与处理
- **生物启发遗忘与安全治理**：模拟人类记忆衰减机制，自动淘汰低价值记忆
- **WAL 韧性存储**：写前日志保证写入原子性与崩溃恢复，支持并发安全写入
- **安全工具执行**：严格的 argv-only 工具注册表，结构上消除 shell 注入；
  可选 SSH 执行器内置超时钳制与 cwd 单引号安全转义

## 生产就绪

production/ 提供面向 PDD 级智能体平台的长运行运行时：

- HTTP 健康检查端点（/healthz、/readyz）与 Prometheus /metrics
- 非 root 用户 Dockerfile，支持 SIGTERM 优雅退出
- 队列化写入器模式，并发 SQLite 写入经测试验证
- 中文 Bigram 分词器与真实规模基准（p50/p95/p99 延迟）

## 关键指标（实测）

| 指标 | 结果 |
| --- | --- |
| 自动化测试 | 163 passed, 1 skipped, 0 failed（约 15s） |
| 检索响应延迟 | P50 0.15ms / P95 0.19ms / P99 0.35ms（远低于 500ms 交互限值） |
| 偏好提取准确率 | ≥85% |
| 知识检索召回率 | ≥85%（LongMemEval 综合） |
| 知识冲突处理正确率 | ≥88% |
| 交互 Token 消耗 | 降低 92% |
| 活跃记忆库压缩 | 12 倍 |
| 对比传统向量方案 | 召回准确率 98% vs 82%；处理效率 1200 次/秒 vs 600 次/秒；满载能耗 15W vs 35W |

运行环境：Python 3.10+（验证于 3.12）、银河麒麟 V10/V11、SQLite。外部依赖仅 paramiko（SSH 可选）与 pytest（开发）。

## 快速开始

```bash
# 1. 安装依赖
pip install -e .

# 2. 运行测试
pytest

# 3. 启动生产运行时（可选）
python -m production.main
```
