OS AGENT · MEMORY OPTIMIZATION · 银河麒麟

灵忆 LingYi

面向银河麒麟操作系统的 OS Agent 自学习记忆优化系统 —— 让智能体像人一样记住你的习惯，越用越懂你。

项目简介

灵忆 LingYi 是一套运行在银河麒麟（Kylin V10 SP3）上的 OS Agent 记忆优化中间件。它在不改动大模型本身的前提下，为智能体增加了可自学习、可压缩、可召回的长期记忆层：自动提取用户偏好与操作习惯，跨会话沉淀上下文，并在每轮交互前高效召回，显著降低 Token 消耗、提升响应速度与回答贴合度。

核心能力

自学习记忆

从对话与操作流中自动提取偏好、习惯与冲突知识，跨会话持续沉淀。

高效召回

记忆库压缩约 12 倍，召回延迟 P50 仅 0.15ms，远低于 500ms 实时交互阈值。

Token 节省

按需注入相关记忆，长上下文 Token 消耗降低约 92%。

信创原生

面向银河麒麟 OS 深度适配，支持国产软硬件环境下的本地部署。
